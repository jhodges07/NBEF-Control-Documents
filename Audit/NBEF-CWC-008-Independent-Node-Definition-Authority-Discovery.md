## N. Resulting authorized Node-definition statements

These are Level 1 statements from this CWC’s Human Engineer answers, plus CWC #7 Node requirement. They are **not** a CONTROL.

1. The canonical term is **NBEF Node**.
2. An NBEF Node is **a distinct unit of education that NBEF recognizes as one bounded subject of the framework**.
3. A Node exists **to identify the units to which NBEF architecture applies**.
4. What makes something one Node rather than part of another is **distinct NBEF recognition as one unit**.
5. The following kinds of things **MAY** qualify as NBEF Nodes: school; classroom; program; learning organization; administrative body; community institution; service provider. This does **not** mean every such thing is a Node. This does **not** state that the list is exclusive.
6. Nodes **MAY** contain subordinate Nodes.
7. Minimum independence presently required is **distinct recognizability as one NBEF unit**. No further independence is defined now.
8. A Node **MAY** hold NBEF-recognized educational authority. The **substance** of that authority belongs to later parent-authority and/or governance CONTROLs.
9. Accountable outcomes **MAY** attach to a Node. The **substance** belongs to the later measurement/accountability CONTROL.
10. An entity becomes a recognized NBEF Node **by later-defined NBEF recognition rules**. Those rules are **not** defined in this CWC.
11. The future Node CONTROL **SHALL** treat lifecycle events as canonical Node subjects. Mechanics are **not** defined in this CWC.
12. NBEF Node meaning is **not** NBBF Node meaning.
