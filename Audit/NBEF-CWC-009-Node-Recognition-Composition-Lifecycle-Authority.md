## 6. Newly established Level 1 authority

### Recognition / entry

1. Until a later CONTROL separately authorizes another recognition process, the **Human Engineer through a controlled CWC** may confer NBEF Node recognition.
2. Valid recognition requires: a distinct educational unit; distinct recognizability; and a bounded identity distinct from other recognized Nodes.
3. Recognition is a **declarative** explicit NBEF act that an entity is a recognized NBEF Node.
4. A **candidate/proposed** Node MAY exist; candidacy is **not** NBEF Node recognition.
5. Two recognized Nodes SHALL NOT be the same bounded unit. Unresolved overlap **blocks** recognition until the R1 recognizer resolves it.
6. Recognition SHALL be **recorded** in this NBEF control-document repository through the authorized CWC/CONTROL process.

### Composition

7. A parent/subordinate relationship is established by **explicit NBEF composition recognition**, using the same recognizer class as R1.
8. A subordinate Node **remains independently recognizable** as one NBEF Node.
9. A Node has **at most one** parent Node.
10. Nesting **is permitted** (subordinate Nodes MAY contain subordinate Nodes).
11. Composition SHALL **NOT** by itself create authority, governance, Signal, or accountability inheritance.
12. Removal from a parent **changes composition only** and does **not** by itself terminate the subordinate Node.

### Lifecycle

13. The future Node CONTROL SHALL treat as canonical Node subjects at least: **recognition/entry; modification; suspension; restoration/reactivation; termination; replacement**.
14. **Activation is distinct** from recognition and **remains to be defined later**.
15. Modification SHALL NOT by itself create a new Node; identity continues unless recognition is withdrawn or superseded.
16. Termination **ends** NBEF Node recognition for that unit.

No Node is recognized by this CWC. No composition is created by this CWC.
